# El Caballero y la Princesa

Un cuento ilustrado y animado: las escenas se mueven mientras bajas con la rueda del mouse (o con el dedo en el celular).
Al final, el lector decide si el caballero debe seguir luchando por su princesa.

Es una sola página (`index.html`) sin dependencias: se puede abrir directamente en el navegador o publicar con GitHub Pages.
